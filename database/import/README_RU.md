# Импорт игровых баз

Сюда помещаются проверенные исходные дампы, совместимые с клонированной ревизией ядра:

- `auth.sql`
- `characters.sql`
- `world.sql`
- `hotfixes.sql`

Файлы данных клиента и многогигабайтные дампы не входят в этот репозиторий и не загружаются из непроверенных зеркал. После размещения дампов используйте документацию выбранного upstream и локальную базу MariaDB из `runtime/database`.

Пользовательский SQL должен находиться в `custom/sql`, быть повторно применимым и иметь собственный файл описания версии.
