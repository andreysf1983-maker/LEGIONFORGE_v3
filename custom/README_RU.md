# Кастомный материал

- `custom/src` — новые независимые C++-скрипты, подготовленные для переноса в `patches/overlay/src/server/scripts/Custom`.
- `custom/sql` — идемпотентные SQL-пакеты, применяемые после резервной копии базы.
- `custom/content` — JSON/CSV-каталоги магазина, локализации и конфигурация баланса.
- `custom/src` — встроенные нативные C++-реализации модулей для LegionCore 7.3.5.26124; `START.bat` автоматически переносит их в дерево ядра перед CMake.

Новые изменения не следует писать непосредственно в `server/source`: эта папка является копией выбранного upstream-ядра и может обновляться bootstrap-скриптом.
